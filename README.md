# Texas Civic Guide

A resident-first civic education platform for Texas cities.

## Purpose

Texas Civic Guide helps residents find city services, understand local government, locate official records, follow public meetings and learn their rights under Texas law.

Official city and State of Texas sources remain authoritative. This project is an independent navigation and education layer and is not affiliated with the City of Copperas Cove or the City of Gatesville.

## Cities

- `/copperas-cove`
- `/gatesville`

## Core rule

**NO SOURCE = NO ANSWER.**

Information presented as fact should be traceable to an official source. Future AI features must remain source-bound.
